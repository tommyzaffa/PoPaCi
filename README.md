# PoPaCi Pictures

Website for **PoPaCi Pictures**, an audiovisual production company based in Ticino, working across cinema, technology and contemporary society.

🌐 Live: https://popaci.com

## Run locally

This is a static website — no build step needed.

```bash
# from this folder
python3 -m http.server 8080
# then open http://localhost:8080
```

Or just open `index.html` in your browser.

## Pages

- `index.html` — home
- `projects.html`, `fiction.html`, `docu.html` — work
- `about.html`, `contact.html` — info
- `css/` — styles · `js/` — scripts · `img/` — images

## Tech

Plain HTML, CSS and JavaScript.
